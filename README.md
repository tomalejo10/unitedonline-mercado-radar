# Mercado Radar — United Online

Bot no oficial que trackea el mercado de personajes de https://unitedonline.com.ar/mercado/,
cruza las bajas de listado contra transferencias de USDT (BEP-20) en BNB Smart Chain para
confirmar ventas reales, y publica el resultado en GitHub Pages.

Corre solo, cada 15 minutos, via GitHub Actions.
